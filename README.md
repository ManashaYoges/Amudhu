# அமுது — Your AI Food & Nutrition Companion

A mobile-first Flutter demo based on the supplied wellness app reference. The current build focuses on the five main destinations and a complete demo Smart Plate analysis.

## Run

Install Flutter, then run `flutter pub get` and `flutter run` from this directory. The source currently uses Flutter SDK widgets only; no API keys or third-party packages are required.

## Included demo flows

- Welcome/login entry and guest access
- Home nutrition summary, daily tip, quick actions, and meal cards
- Meal plan calendar and sample meals
- AI chat with local sample replies
- Smart Plate with detected foods, estimated portions, macros, vitamin and mineral values, balance score, insight, and save/ask actions
- Smart Fridge ingredient and recipe suggestions
- Profile goals and settings

All personalized values and AI/ML actions are sample data. Camera and upload buttons currently show demo feedback; they do not access the device camera. Firebase Authentication, Firestore, Storage, MongoDB API, and external AI/ML services are not configured in this demo. Nutrition displayed for image analysis is labeled as estimated.
